# Research Portfolio

The homepage introduces the research portfolio and summarizes four selected
projects. Each project card opens a dedicated long-form page:

- Task-aware robotic weld inspection
- Vibration compensation for material deposition
- Energy-aware AUV guidance and control
- Risk-aware maritime navigation

Each project page contains two labeled media placeholders for future images and
results. The content is based on the latest CV and statement of purpose supplied
in November 2026. The navigation CV link opens the latest CV separately.

## Publish with GitHub Pages
1. Create a repository named `YOURUSERNAME.github.io`.
2. Upload `index.html`, `styles.css`, and `cv.pdf` to the repository root.
3. Commit to the `main` branch.
4. In GitHub: Settings → Pages.
5. Under Build and deployment, choose **Deploy from a branch**.
6. Choose `main` and `/ (root)`, then Save.
7. Visit `https://YOURUSERNAME.github.io`.

The CV contains a generic LinkedIn URL rather than a personal profile URL, so
LinkedIn is not displayed on the homepage. The Google Scholar profile is linked.
