# Research Portfolio

The homepage preserves the portfolio structure: introduction, About, Research,
Projects, Publications, and Contact. Content is based on the supplied `cv.pdf`.
The navigation CV link and View CV button open that original PDF separately.

## Publish with GitHub Pages
1. Create a repository named `YOURUSERNAME.github.io`.
2. Upload `index.html`, `styles.css`, and `cv.pdf` to the repository root.
3. Commit to the `main` branch.
4. In GitHub: Settings → Pages.
5. Under Build and deployment, choose **Deploy from a branch**.
6. Choose `main` and `/ (root)`, then Save.
7. Visit `https://YOURUSERNAME.github.io`.

The CV contains a generic LinkedIn URL rather than a personal profile URL, so
LinkedIn is not displayed on the homepage. The Google Scholar profile is linked.
